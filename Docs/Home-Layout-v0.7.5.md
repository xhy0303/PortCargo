# 首页视觉整理 v0.7.5

用户要求首页更整洁，并明确港口图应尽量铺满屏幕可用区域，不能在不同尺寸上维持一张固定的小卡片。广告功能沿用0.7.4。

## 最终布局

- 首页使用统一深蓝底延伸至安全区外，消除上下露出的重复港口画面；文字和操作仍在安全区内。
- 港口场景铺满可用宽度，高度占满标题和操作区之间的剩余空间。背景等比覆盖并偏向天空／地平线，船与吊机完整保留，码头前景贴底。允许裁去背景装饰边缘，不拉伸图片。
- 保留黄色闯关主按钮；无尽入口及四个辅助入口降低视觉重量，所有入口与原有免费玩法保留。
- 将闯关进度靠近主操作；隐藏首次无尽模式的泛化说明，保留已有无尽存档的真实进度。
- 广告仍有独立底部区域。矮屏压缩装饰间距，并将两项主操作改为并排，保留广告和全宽港口；不以隐藏首页广告换取排版空间。保存失败等既有故障保护保持不变。

## 实现边界

修改 `HomeView.cs`、`HarborButton.cs` 的首页专属样式选项和版本构建配置。`quiet` 默认关闭，只有首页启用。原生与激励广告适配器、广告位ID、奖励判定及其他游戏页面布局未修改。
