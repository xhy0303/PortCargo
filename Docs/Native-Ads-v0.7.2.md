## 交互边界

原生卡片仅使用首页底部空余区域与完成结算页预留空间。首页不再为广告缩小或移动港口、按钮，也不覆盖港口画面；底部不足时省略广告。开始游戏、下一关／下一程与返回按钮不等待广告；游玩、暂停、设置、玩法说明、隐私、选关、确认弹窗、激励广告及保存失败时不展示原生卡片。没有广告返回或网络失败时不弹出阻塞提示，也不改变免费提示、撤销、重开和进度规则。

布局空间不足时不显示广告。原生层高于 Unity Canvas，导航开始时需要立即隐藏，异步完成时重新验证当前页面；不能以首页 GameObject 仍可见作为展示条件。关闭卡片和加载失败在本次停留内保持，不进行循环重试或自行定时刷新。

## 接入与验证

原生适配器、UI 预留区域、坐标转换及后台生命周期均在本工程内实现。SDK 包版本不因本功能升级。固定 SDK 的 C# 层未接出 CustomAd 的尺寸事件，因此新增自有 `.jslib` 调用 `wx.createCustomAd` 并监听加载、错误、关闭、隐藏、尺寸事件；不修改 SDK 内部对象。

微信 [官方 API 定义](https://raw.githubusercontent.com/wechat-miniprogram/minigame-api-typings/master/types/wx/lib.wx.api.d.ts) 说明 `CustomAd.onResize` 仅对部分模板返回尺寸。本工程优先检查回传尺寸；无回调时在加载完成后等待 0.25 秒，再按用户后台唯一 20:7 卡片、整个安全区宽度及向上取整高度回退。预留区额外增加 12 个 UI 参考单位吸收 CSS 像素取整。回调尺寸超过保留区时在 JS 层立即隐藏销毁。回退基于本次模板配置，不代表任意其他广告模板都适用；两个广告位的实际样式与尺寸仍需手机验收。

原生加载及展示各有 10 秒上限，超时静默结束本次停留的广告尝试。每次有效页面访问最多一次创建尝试，没有自设刷新计时器；后台恢复统一延至下一个 Unity Update，防止微信多个 onShow 监听器顺序不同而误判失败。Unity 底部原点的屏幕像素按窗口宽高映射为微信 CSS 像素，避免高 DPR 设备错位。
