0.7.3 已恢复尺寸合适的首页广告，并新增暂停、设置及局内单格广告。首页为广告和港口图分配独立区域；港口组合画面整体等比缩放，按钮保持可用。局内只调整标题、标题底板及船体位置，棋盘、暂存区与操作按钮不因广告加载、失败或关闭而移动。文字修正版0.7.4已交付，当前剩余工作是其余微信页面操作及手机真实广告验收，而非等待广告位 ID 或代码接入。

## 尺寸能力核查与后续验收

微信官方 [小游戏 API 定义中的 CustomAd](https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/types/wx/lib.wx.api.d.ts) 说明模板宽度可配置时按设置宽度等比缩放，部分模板提供 `onResize`；并非所有模板都接受任意宽度。

2026-10-25 已对当前首页广告位实测：请求260 CSS宽时，平台通过尺寸回调返回300×104.4。实现以该实际限制保留302 CSS宽及高度余量；最终0.7.3模拟器首页显示通过。不能把这个实测限制推广为所有微信原生模板的统一最小宽度。

局内单格没有返回尺寸事件或原生实际宽高字段，采用仅绑定到已探测广告位的保守80×120 CSS包围区，布局预留82×122 CSS；其尺寸依据独立于横卡20:7比例。平台若返回实际尺寸，仍优先检查并在越界时立即隐藏。变更模板或广告位后需要重新测量。

手机验收仍需同时看到首页完整港口图、可操作按钮和真实广告，并逐页检查暂停、设置、局内和结算的真实组件尺寸及跳转返回。不得以裁切广告、遮挡原生元素或省略首页广告冒充需求完成。
