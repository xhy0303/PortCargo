## 2. 资产总表

“画面需要这个元素”不等于“需要独立 PNG”。简单图形可继续由 uGUI、程序几何和 TMP 实现；同一按钮、船或货箱不按关卡重复出图。

| 资产 | 数量/复用 | 当前可用替代与交付要求 |
| --- | --- | --- |
| 首页港口展示 | 1 组，可拆船/吊机/码头/水面 | 现有 `HarborPreview` 几何占位；以后交可编辑源文件及分层或整张装饰图，不能含动态进度和按钮 |
| 游戏港口背景 | 1 套 | 纯色/几何可保留；插画避开船、箱堆、文字和安全区，可裁切部分需标明 |
| 标题标志 | 0–1 个 | 可直接使用文字；不含当前关号、版本、进度 |
| 四类货箱 | 4 个基础样式 | 颜色 + 竖条/圆点/斜线/十字；四类留白和视觉大小一致，纹样不能靠颜色代替 |
| 货物小图标 | 复用上述 4 类 | 当前船、预告船、暂存、飞行影像和首页示意保持一致，不另做矛盾图案 |
| 货箱高亮/状态 | 0–1 个框，状态可程序处理 | 普通顶部、被压暗、按下、提示、非交互影像；不必出 20 张独立状态图 |
| 通用船身、船舱 | 1 套复用 | 需求图标和 0/3 数字独立；当前船与 3 份离港影像同步替换 |
| 箱堆底座 | 0–1 张复用最多 6 次 | 可用简单线/色块；不遮住最底箱纹样 |
| 暂存槽 | 1 样式复用 3 次 | 空槽也清楚可数；满槽叠放实际货箱，保留规则层未来第 4 格能力 |
| 通用面板与遮罩 | 0–1 套 | 可用色块/描边；说明、暂停、确认、设置、选关、结果共用 |
| 主按钮、次按钮 | 各 1 样式 | 默认/按下/禁用，可用 tint 或缩放；特殊纹理无法染色时才另出状态图 |
| 关卡格与状态标记 | 0–1 套 | 可复用按钮；数字动态生成，不做 50 张；锁定与已完成可用文字或图标 |
| 短提示/保存失败底板 | 0–1 张 | 可复用通用面板，保留可点击重试入口 |
| 模式识别图 | 0–2 个，可选 | 闯关/无尽可直接用文字 |
| 教学示意 | 0–3 组，可选 | 推荐组合实际箱、船、槽组件；对应取顶部、同类装船、其余暂存 |
| 通关标记与庆祝碎片 | 0–1 套，可选 | 完成勾、轻量碎片即可；减少动效时仍有文字结果 |
| 应用/小游戏图标 | 1 个母版，发布时导出 | 后续平台接入再按实际规格导出，不以此代表微信已可发布 |
| 正文/标题字体 | 1–2 个字体，可复用 | 当前 Noto Sans SC OFL 子集可保留；更换交 TTF/OTF、许可，重建静态 TMP 字库 |
| 音效 | 取箱、出港、通关、无效操作各 1 | 现有 4 个合成音可保留；替换提供 WAV 源与许可，响度一致；菜单音可选 |
| 背景音乐 | 1 段循环 | 当前合成循环可保留；替换提供无缝循环、授权和混音说明 |

共享图标若采用图片，统一制作：暂停、撤销、提示、船队、首页、设置、音效、音乐、减少动效、帮助、锁定、完成、上一页/下一页、保存重试、退出、返回/关闭。开关需有开/关语义；单色图可程序换色，不必另出多种颜色文件。

不需要角色、皮肤、商店、货币、抽奖、排名、签到、奖励广告图片。默认不需要视频、骨骼角色、Spine 或动画序列帧；现有取箱、离港、高亮和庆祝可继续由程序反馈完成。

## 3. 不用外部资产也必须保留的要求

- 布局：遵循上面的共同分区。短屏优先缩装饰和间距；关卡号、无尽程数、装载量、进度和按钮文案保持动态。设计参考 390×844，当前 Canvas 基准 720×1280，两者是不同坐标单位。
- 适配：检查 320×568、360×800、720×1280，尤其六堆密集局面 L10/L50；主要操作目标至少 44 屏幕像素。微信安全区、胶囊与 CSS 像素另行实测。
- 状态：按钮有按下和禁用，选关有锁定/可玩/完成，提示有可用/搜索中/用完；不能只靠颜色说明状态。四类货物在灰度、变暗和高亮时仍可分辨。
- 输入：装饰不拦截射线；按钮和顶箱热区与显示一致；同箱按下/抬起才生效，拖动取消，单指归属不变。模态弹窗不能点穿。
- 返回：首页打开的设置/帮助回首页，暂停打开的回暂停。Escape 跟随当前页面返回；首页和桌面关闭触发退出确认。
- 进度：闯关与无尽分别保留局面、撤销和提示；回首页不重置。重开、替换未完成闯关需确认，取消保持原局。旧档继续兼容。
- 异常：保存失败保留重试入口；退出失败可重试或留在游戏；明确选择“仍然退出”才放弃最近未落盘动作。启动错误可重试，无删除进度按钮。
- 玩法：只取顶部、同类装船、三格暂存、完整撤销、每局一次成功免费提示。暂存满但仍能合法取箱时不弹失败；真正卡住后可撤销/重开/回首页。
- 教学：首次三页说明可返回，完成后不强制重复；玩法说明随时可打开。船队仅查看，不增加换序交互。
- 动效/声音：音效、音乐、减少动效设置有效并持久保存；减少动效仍保留可读状态，不以动画结束驱动规则提交。
- 文案/性能：所有中文需进入静态 TMP 字库；不使用在线字体掩盖缺字。保持一个 EventSystem 和原有三个 Canvas；资源本地随包，首包与低端手机性能后续平台验证。

## 4. 需要覆盖的页面

| 页面 | 必须覆盖的内容或分支 |
| --- | --- |
| 首页 | 新玩家开始、老玩家继续、闯关进度、无尽程数、选关/设置/帮助/退出、保存通知 |
| 首次引导与帮助 | 三页规则、前后翻页、返回、首次末页开始游戏 |
| 局内与船队 | 当前需求/数量、未来两船、完整只读船序、箱堆、暂存、撤销/提示/暂停 |
| 选关 | 8 项分页、锁定/可玩/完成、最后页仅 49/50、返回、切关确认 |
| 暂停与设置 | 继续、重开、选关、说明、设置、回首页；音效/音乐/减少动效开关 |
| 隐私与反馈 | 本机保存说明、反馈操作信息、版本、返回 |
| 闯关/无尽结算 | 下一关/下一程、重玩、回首页；最后一关可选关和进入无尽；全部完成状态 |
| 卡住 | 明确可恢复，撤销优先，重开仍确认，回首页 |
| 确认/异常 | 重开、替换未完成关卡、退出；保存失败重试/留在游戏/仍退出；启动失败重试 |

## 5. 文件与接入位置

交付可编辑源文件、Unity 所需 PNG/WAV/TTF 和来源/许可。图片注明透明、裁切区域、pivot、可拉伸边界；按钮/面板需注明 9-slice，像素风再使用 Point 过滤。名称以用途稳定命名，逻辑货类 R/B/G/Y 不变。

新图可放 `Assets/PortCargo/Art/Sprites/{Cargo,Harbor,UI,Icons,FX}`；Fonts、Audio 沿用现有目录。未使用的概念稿留在工程外，原资料不改。更换资产尽量保留 GUID，使用 Unity 编辑器/API 重新绑定引用。

| 接入位置 | 替换边界 |
| --- | --- |
| `Runtime/HomeView.cs`、`HomePanel/HarborPreview` | 首页展示与按钮意图；港口组可独立替换 |
| `Runtime/GameFlowController.cs` | 页面/返回/确认，不放美术资源生成或规则逻辑 |
| `Runtime/GamePresenter.cs` | 两模式会话与保存，换 UI 不改存档合同 |
| `Runtime/DialogView.cs`、`OverlayLayer/Dialog/Card` | 12 个复用按钮；可换专用面板，保留交互与返回路径 |
| `Runtime/CargoGraphic.cs`、`BoxView.cs` | 统一货物状态，覆盖棋盘、暂存、需求、预告、反馈影像 |
| `Runtime/BoardView.cs`、`HudView.cs` | 最多 6 堆×6 高与 36 箱池；船区/货堆/暂存/底部按钮 |
| `Runtime/FeedbackPlayer.cs`、`SafeAreaLayout.cs` | 反馈池、减少动效、安全区；布局和命中区域一致 |
| `Tools/AddFlowShell.cs`、`Tools/PolishScene.cs` | 编辑器制作工具，不作为运行时生成界面的入口 |

当前只有 36 个 `BoxView` 保持 prefab 实例引用；`GameHud`、`ShipView`、`StackView`、`Dialog`、`HomePanel` 的 prefab 主要是制作快照。替换后要核对 Bootstrap 实际对象、3 份离港船和全部货物显示，不能假定只改 prefab 就全部更新。

完成替换后简单回归：首页进入/返回、真实货箱点击、模态阻挡、撤销、结算下一关、两模式切换、独立进程续玩及保存异常；检查窄屏、密集局面、长文案、静态字库和三个声音/动效开关。无需为每个资产另写测试。
