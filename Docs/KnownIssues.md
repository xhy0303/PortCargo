# 当前边界与后续工作

## 本机试玩范围

本轮交付为像素夜港轻扁平美术、三首音乐轮播的 macOS 本机 v0.4.1，包含完整首页、页面导航、结算与退出流程，保留 50 个固定关卡与无尽模式。默认 3 格可解，广告关闭，核心玩法与存档可离线运行。Unity 使用用户指定的 6000.3.25f1。macOS 包含 Apple Silicon 和 Intel 两种架构；本次只在当前 Apple Silicon Mac 执行，Intel 硬件未测。

## 待用户试玩

自动测试验证了状态和输入路径，不能代替新玩家理解测试。教学 8–20 秒、普通关 20–45 秒、90 分位不超过 90 秒仍是体验目标。用户已试玩原第十关。本轮新增关卡与无尽难度仍需统一试玩校准，重点记录过难关卡、重复感、撤销和提示使用情况。自动求解耗时、自动点击通关耗时都不作为人类通关成绩。

当前已接入用户准备的像素夜港轻扁平素材及合成声音，接入说明见 Art-Integration-v0.4.md。v0.4.1 已完成三首音乐两轮自然轮播、实际输出及开关/续播自动检查，详见 Music-v0.4.1.md；个人听感与手机扬声器效果仍需试听，不能把数值检查当成人工试听。

## 微信与发布待办

按用户指示，微信小游戏统一后接。本轮没有实际微信导出、AppID 绑定、开发者工具预览、Android/iOS 微信设备验证、安全区/胶囊实测、真实广告或后台审核。WebGL 构建守卫明确阻止把尚未适配的平台版本作为可用成品。

广告接口默认返回不可用；规则层有按 run 归属的提示/扩位权益合同，但没有奖励协调器、广告账本、频控及 SDK 回调集成，因此 R07/R08 只覆盖规则权益和旧 run 拒绝，不能视为广告 A01–A06 通过。T08 在微信平台适配后继续。50 关和无尽已按最新要求纳入，UI 已按另一个对话准备的正式资产接入；原需求见 Art-UI-Handoff.md，当前状态见 Art-Integration-v0.4.md。

## 验证限制

- 当前 v0.4.1 完成 602.1 秒 / 106 轮长测，运行错误 0、对象和音源稳定；见 Music-v0.4.1.md。下列 v0.3/v0.4 记录为历史范围。

- v0.3 已完成 604.1 秒 / 106 轮连续运行，最终 PASS；对象与音源数量稳定，未观察到持续内存增长。旧 572.1 秒记录仅保留为历史未完成结果。该结果属于 v0.3；本轮 v0.4 仅做美术接入后的简单回归，没有重做十分钟长测。十分钟结果不替代任意时长或低端手机性能验收，详见 Technical-Checks-v0.3.md。

- v0.1 的 10 关指针结果保留为历史证据；v0.2 抽样新关卡与无尽，v0.3 抽测完整页面流程与恢复路径，未逐一人工试玩全部 50 关。普通非 Development 包单独构建，开发驱动不进入交付包。
- 30 FPS 是目标帧率设置。当前 Mac 上的规则耗时、内存和回归，不证明低端手机 100 ms 触控响应，也不证明微信包体、冷启动或弱网表现。
- v0.4 独立开发包 L10/L50 在 320×568、720×1280、360×800 的密集布局和实际顶箱点击通过，不代表所有异形屏安全区。微信 CSS 像素与渲染像素换算尚待平台接入。
- macOS 程序未进行商店签名或公证；当前机器可执行验证，不承诺其他机器的分发审核通过。
- 原始工程自带的 2D 套件等依赖保留；尚未针对微信包体裁剪依赖。Mac 包大小不可用于预测小游戏首包。

## 页面与替换边界

首页、局内和通用 Dialog 已采用像素夜港轻扁平风格；当前船、三份离港影像、棋盘/暂存/飞行货箱统一替换。标题与数量均为动态文字。只有 BoxView 保持 prefab 实例引用，其余制作快照已同步，但后续仍需同时核对 Bootstrap 实际对象。生成插画的像素密度不完全一致，Point 过滤不等于严格 pixel-perfect。

## 本机退出日志

v0.4 普通包本轮原生退出、取消与两进程重启检查也已通过，原存档保持；见 `Evidence/v0.4/release-native-result.json`。程序退出时仍记录 ComputeBuffer 自动回收提示，没有新增游戏脚本异常。

v0.3 普通包已完成原生首页退出、窗口关闭、取消退出及两独立进程重启，均正常退出码 0，现有进度保持。记录见 `Evidence/v0.3/technical-20261016/release-native-result.json`。普通包及 v0.3 开发流程程序正常退出时仍有 Unity/Mono 线程结束及 ComputeBuffer 自动回收提示，日志见 `Evidence/v0.3/player-flow-aligned-*.log`；未见 PortCargo 脚本异常。具体内部来源未定位，不能直接解释为持续内存泄漏。运行中长测趋势单独记录。

## 构建日志说明

最终构建无编译错误。Pipeline 会输出一条“enableInBuilds = false”的警告，这是预期的运行服务关闭提示，不是游戏异常。发布预览中不包含 Pipeline 运行服务/代码执行程序集。

`Evidence/diagnostics` 保留早期失败或作废的工具记录：直接调用工具注入指针未能驱动 UI；在 Editor 工具上下文读取 Screen 得到的是编辑器窗口尺寸；同步构建触发 5 秒工具超时。这些记录不计入通过结果。最终输入与尺寸检查改在游戏正常帧中执行，构建改用 Editor update 消费请求。
