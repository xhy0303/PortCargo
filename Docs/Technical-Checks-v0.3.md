## 隔离、构建和复现

密集检查和长测使用 `/tmp/portcargo-technical-20261016-01`，测试夹具仅在该目录全解锁、跳过首次说明。实际动作经过 Input System 和现有界面，不直接调用规则方法冒充玩家点击。

新增 `DevelopmentTechnicalChecks.cs` 和启动参数位于 `UNITY_EDITOR || DEVELOPMENT_BUILD` 分支，普通包不包含这些驱动。使用方式见 [Build.md](Build.md)。开发包构建清单保存在证据目录 `validation-build.json`。

普通包检查按用户已有授权读取并保存现有进度，仅操作退出/取消/关闭窗口，不进行关卡动作；检查前后比较完整两模式局面、撤销数据与设置指纹。

此次不改变美术、关卡内容或游戏规则。微信导出、手机安全区、触控与性能、广告和发布仍待后续平台接入。Unity 退出时的 ComputeBuffer 自动回收提示继续单独记录，不能当作游戏脚本异常或本次内存持续增长证据。
