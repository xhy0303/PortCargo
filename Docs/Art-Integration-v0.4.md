# v0.4.0 像素夜港轻扁平接入

2026-10-16。依据工作区 `美术资产/2026-10-16_像素夜港轻扁平` 的正式素材和接入说明，替换现有 Bootstrap 的画面与声音。沿用 Unity 6000.3.25f1、50 关、无尽和两模式独立存档。本轮已由用户授权进入实际接入。

## 已接入

- 首页：夜港背景、独立空船、吊机与码头组件；动态标题、两模式进度与主次入口；四个底部导航按钮。
- 局内：保持纵向分区，统一当前船与三份离港影像；后两船显示实际纹样与数量；货堆、暂存、飞行货箱统一映射 R 竖条、B 圆点、G 斜线、Y 十字。方形货物不拉成长方形。
- 控件：主/次按钮默认、按下和禁用图；通用/警告面板与遮罩；共享功能图标；设置使用开关轨道和滑块，文字仍明确显示开/关。
- 选关：每页八格，四列两行，关号和状态独立换行，已完成/锁定/当前关区分；翻页和返回继续使用原事件。
- 教学与结果：三张规则示意、完成标记和三类庆祝碎片；减少动效仍保留结果文字。
- 声音：取箱、出港、通关、拒绝四种事件替换；新增菜单点击音，复用原六个效果声源；原音乐源绑定 24 秒循环。
- 应用图标：母版用于本机包图标；不代表微信图标已经提交或审核。

72 张原始 PNG 中采用 63 张：62 张进入运行主题，应用图标单独绑定到 PlayerSettings。其余九张为未采用的备用图标/提示框，留在工程外原包。六个 WAV 均已绑定。字体文件与现有字库相同，保留原 GUID 和静态 TMP 图集，不重复导入。

## 可维护性与导入

`Art/FlatPixelTheme.asset` 保存主题引用；`HarborButton` 仅负责按钮皮肤、图标、开关和菜单音；`HarborTextPlate` 管理短文字底板。`CargoGraphic` 保留原组件类型与点击 RectTransform，增加共享 Sprite 显示。`GameFlowController` 只额外传递当前关号给选关外观，不承担美术生成。

`Editor/FlatPixelArtInstaller.cs` 通过 Unity API 修改已存在场景与预制体，菜单为 `PortCargo > Apply Flat Pixel Art`。不重新生成工程，不在运行时创建整套 UI。场景、HomePanel、GameHud、ShipView、Dialog、StackView 与 BoxView 制作快照同步更新；BoxView 的 36 个实例保留 prefab 关系。重新应用时也检查底板始终位于文本之前。

PNG 按资产清单使用 Single、Full Rect、Point、Clamp、无 mipmap、无压缩、正确 pivot/border；9-slice 仅用于可拉伸面板、按钮和开关轨道。港口背景按比例覆盖裁切，船与方形组件保留比例。字体 SDF 设置不改为 Point。

音频按 PCM/原采样率导入，BGM 双声道、音效单声道；没有增加 AudioSource。音乐音量 0.22、音效 0.5 是本机初始混音，仍由原有设置控制。音频文件与来源包逐字节相同；声音设备的主观听感、连续三次循环试听与微信声音策略未由自动检查代替。
