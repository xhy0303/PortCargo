## 2. 通用图标与开关语义

原清单以文字组合列出的功能图标，展开后覆盖以下 18 个用途。表中使用正式资产 ID，PNG 文件位于 `01_可交付/Sprites/Icons/`，SVG 源位于 `02_可编辑源文件/Icons/`。一个图标可以在多个页面复用。

| 用途 ID | 中文含义 | 典型位置 | 语义核对 |
| --- | --- | --- | --- |
| icon_pause | 暂停 | 局内顶栏 | 不与设置齿轮混淆；打开暂停页 |
| icon_undo | 撤销 | 局内底部、卡住页 | 表示回退一步，不是返回上一页面 |
| icon_hint | 提示 | 局内底部 | 可用/搜索中/用完另有文案或状态 |
| icon_queue | 船队 | 局内预告旁 | 只查看队列，不暗示换船或调整顺序 |
| icon_home | 首页 | 暂停、结果、卡住 | 回首页保留局面 |
| icon_settings | 设置 | 首页、暂停 | 音效/音乐/减少动效等设置入口 |
| icon_sound | 音效 | 设置 | 对应效果声，与音乐分别控制 |
| icon_music | 音乐 | 设置 | 对应 BGM，与音效分别控制 |
| icon_reduced_motion | 减少动效 | 设置 | 降低运动效果，不等同于声音关闭 |
| icon_help | 帮助 | 首页、暂停 | 打开玩法说明 |
| icon_lock | 锁定 | 选关 | 与“未解锁”语义一致，不可交互 |
| icon_complete | 完成 | 选关、结果 | 与“已完成”语义一致 |
| icon_previous | 上一页 | 教学、选关分页 | 只在存在前页时显示或启用 |
| icon_next | 下一页 | 教学、选关分页 | 与下一关/下一程的动态文字区分 |
| icon_retry_save | 保存重试 | 首页、局内、退出失败 | 必须有可点击操作，不仅是提示装饰 |
| icon_exit | 退出 | 首页、退出确认 | 明确退出，不与关闭弹窗混淆 |
| icon_back | 返回 | 帮助、选关、设置等 | 返回调用页面，保持正确来源 |
| icon_close | 关闭 | 可关闭弹窗 | 关闭当前层，不直接退出游戏 |

开关组件另外覆盖“开/关”两种状态。应使用滑块位置、开关符号或动态“开/关”文字，与颜色共同表达。可选补充的开始、重开、警告、闯关、无尽图标用于完整呈现页面；它们不增加新玩法。

图标可采用单色染色，不必为每个功能导出多套颜色。调色时对背景保持对比，禁用图标不能亮得像主操作。图标与动态文字同时出现时，确保图形的含义和文案一致。

## 3. 页面覆盖与组合方式

以下页面使用同一资产包组合，不要求每个页面各交一张整屏 PNG。整屏预览用于观察组合关系，运行界面仍由现有组件与动态内容生成。

| 页面或分支 | 使用的资产组合 | 必须显示的运行信息 | 必须保留的操作 |
| --- | --- | --- | --- |
| 新玩家首页 | 首页港口构图、主/次按钮、功能图标 | 闯关进度、无尽状态、标题 | 开始闯关、无尽、选关、设置、帮助、退出 |
| 老玩家首页 | 与新玩家首页复用 | 继续入口及两模式各自进度 | 继续当前局；回首页不清空存档 |
| 首页保存通知 | 提示底板、保存重试图标 | 保存失败/恢复状态 | 可点重试；必要时让装饰让位 |
| 首次教学 | 面板、三组示意、翻页图标 | 第 1/2/3 页规则 | 前后翻页、返回、末页开始；完成后不强制重复 |
| 随时帮助 | 复用教学面板和示意 | 当前规则页 | 返回来源页面；不强制重置教学状态 |
| 普通局内 | 游戏背景、船、四类箱、底座、槽、按钮 | 关卡、当前需求/数量、后两船、暂存、提示状态 | 顶箱点击、撤销、提示、暂停、船队 |
| 无尽局内 | 普通局内共用素材 | 无尽程数与实际局面 | 与闯关分别保留会话 |
| 船队 | 通用面板、货类小图标 | 完整只读船序 | 返回，不能排序或换船 |
| 选关 | 关卡格、锁/完成标记、翻页与返回 | 8 项分页、实际关号和状态 | 切关确认；最后页仅 49/50 |
| 暂停 | 通用面板、主/次按钮 | 暂停标题与保存说明 | 继续、重开、选关、说明、设置、回首页 |
| 设置 | 通用面板、音效/音乐/减少动效图标及开关 | 各项真实开关状态 | 修改持久化、隐私与反馈、返回来源页面 |
| 隐私与反馈 | 通用面板和返回按钮 | 本机保存说明、版本、反馈操作信息 | 返回，无账号/商店等额外入口 |
| 闯关通关 | 面板、完成标记、轻量庆祝 | 当前完成结果 | 下一关、重玩、回首页 |
| 无尽完成一程 | 与通关共用 | 当前程完成结果 | 下一程、重玩、回首页 |
| 全部 50 关完成 | 与结果页共用 | 全部完成状态 | 选关、进入无尽、回首页 |
| 真正卡住 | 警告图标、通用面板、撤销按钮 | 可恢复说明 | 撤销优先；重开仍确认；回首页 |
| 重开/替换关卡确认 | 确认面板、主/次按钮 | 将替换的进度说明 | 确认、取消；取消不改原局 |
| 普通退出确认 | 确认面板与退出图标 | 保存与退出说明 | 退出、留在游戏 |
| 保存失败后的退出 | 错误提示板与重试按钮 | 最近动作未落盘状态 | 重试、留在游戏、明确“仍然退出” |
| 启动失败 | 错误面板、重试图标 | 可读错误与恢复说明 | 重试；不提供删除进度按钮 |

参考稿“暂存已满”视觉只能作为警告样式参考：是否卡住由合法动作决定。参考图只有一部分页面和示例关号，不能据此缩减上述覆盖范围。

## 4. 状态复用合同

| 组件 | 基础文件 | 由运行时提供的内容 | 不得烘焙或误用的内容 |

| 面板 | 可拉伸底板与遮罩 | 标题、正文、按钮数量和高度 | 只容纳某个示例短文案的整张截图 |

| 结果特效 | 完成标记与碎片 | 是否减少动效、实际结果文字 | 动画完成才提交关卡结果 |

## 5. 可编辑源与交付格式核对

| 资产类型 | 可编辑源的实际能力 | Unity 使用格式 | 需随包核对的说明 |
| --- | --- | --- | --- |
| UI、货箱、功能图标和教学组件 | SVG 可编辑形状/坐标/颜色；脚本可重建对应图形 | PNG | 尺寸、透明、pivot、边界、建议用途、源文件路径 |
| 港口生成插画组件 | PNG 位图母版可整体编辑或重新生成；内部不自动分层 | PNG | 生成记录、透明状态、裁切和对齐说明 |
| 通用空船 | 原生像素 SVG 可编辑内部几何，`build-ship.cjs` 可重建 | PNG | 甲板线、货物安全矩形、船底对齐点；不可 9-slice |
| 首页港口组合 | `home_harbor_layers.svg` 内嵌四张 PNG，可独立移动组件 | 需要时导出合成 PNG，或在 Unity 分组件组合 | 背景、吊机、空船、码头的层序；更新源图后同步内嵌内容 |
| 应用图标 | PNG 母版与生成记录 | 发布时按实际平台规格另导出 | 安全边距、是否已有圆角、不可误称通过平台审核 |
| 字体 | 已重命名字体子集与字符清单；不能凭空增补缺字 | TTF，后续重建 TMP | OFL、来源、330 字符限制、新增字符流程 |
| 音效与音乐 | 合成制作源与参数 | WAV | 采样率、声道、位深、时长、循环与混音说明、来源 |

SVG 文件名不等于已经有 Unity 组件。可移动的位图构图层不等于每个插画物体都具有内部矢量图层。生成插画不保证统一整数像素网格；Point 导入仍需按最终显示尺寸检查。

## 7. 明确不在本包范围的内容

原清单不要求角色、皮肤、商店、货币、抽奖、排行榜、签到或奖励广告素材，也不要求视频、骨骼角色、Spine 或逐帧动画序列。本包不借制作素材添加这些功能。

不修改现有关卡数据、规则、存档、提示算法或无尽生成器；不导入工程、不替换场景引用、不发布小游戏。应用图标母版和完整资源目录不等于平台审核、首包限制或目标真机性能已经合格。

## 8. 最终交付时的对照方法

交付接收人按以下顺序核对，而不是仅统计 PNG 总数：

1. 从 20 类表逐行找到最终清单中的资产或明确的复用/动态文本方式。
2. 核对 18 种功能图标用途及开关开/关语义；检查是否把返回、撤销和退出混为一图。
3. 打开四类货箱，分别在正常、压暗和高亮背景下查看，尤其补查黄色十字。
4. 打开港口背景、透明组件和首页构图源，确认透明、层序、链接依赖及可编辑程度与说明一致。
5. 查看面板、按钮、槽和关卡格的边框与最小尺寸；从清单逐项读取 9-slice 和 pivot，不凭预览猜值。
6. 查看全部页面组合表，确认每个分支可由已有素材和动态文本构成，不需要临时从整屏图裁按钮。
7. 核对字体子集、许可和字符表一起存在；对新增文字另做覆盖检查。
8. 核对五类音效及 24 秒循环 BGM 的文件、制作源与来源，并按声音说明试听。
9. 对照本次验收记录明确哪些文件检查已执行，哪些 Unity 接入、构建、独立进程与目标设备验证仍待后续完成。

本轮只交付工程外资产与文档，未修改游戏工程。最终完成数量和已执行检查以清单与验收记录为准，本文中的覆盖目标及操作步骤不自动构成运行验收结论。
