## 使用约定

- 游戏代码、已接入素材、关卡配置和场景仍以 `Assets/PortCargo/` 为准。本目录保存创作资料与交付源，不自动覆盖运行时资产。
- 原始规格、历史截图和素材验收记录保留当时语境。例如首批 10 关、50 关截图或“尚未接入 Unity”的旧说明，不代表当前游戏状态。当前版本从[工程说明](../README.md)及[开发文档索引](../Docs/README.md)进入。
- `文档/立项参考_三款小游戏总体方案_2026-09.docx` 是跨游戏规划的历史快照；原件仍属于“微信小游戏”总目录，快照不随总规划自动更新。
- 历史 JSON、CSV、只读副本和校验记录中的绝对路径保留为来源信息，不要求这些旧路径继续存在。旧总目录下五类专属目录统一映射为本仓库的 `ProjectContent/<原相对路径>`，逐文件对应关系见[迁移清单](../Docs/Evidence/reorganization-20261026/migration-manifest.json)。
- HTML 预览及素材引用保留原有相对目录关系；使用浏览器打开相应 `index.html`。归档中的绝对路径历史链接通过迁移清单定位，不在原总目录保留软链接或副本目录。
- 新批次按日期建立目录，保留原始文件、源文件、来源许可和交付校验；不要将单款游戏资料放回多游戏总目录。

这里的美术和推广 ZIP 是资料交付包。游戏编译产物仍放在工程根部 `Builds/`，遵循现有 Git 忽略规则。
