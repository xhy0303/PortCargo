# 像素夜港 · 轻扁平版

2026-10-16。依据用户反馈“在这个像素风格的基础上，把整体都稍微扁平化一点”，对上一版像素夜港进行视觉修订。

[打开新旧对比](index.html) · [轻扁平版原图](images/05-pixel-night-port-flat-v2.png) · [上一版原图](../2026-10-15_五种界面风格/images/05-pixel-night-port.png)

调整重点：

- 按钮、弹窗与面板减少厚边、凸起底座、亮面高光和投影，保留清楚的像素轮廓与状态层级。
- 货箱以正面色块和纹样识别为主，减弱倒角、铆钉、反光和侧面厚度。
- 船舶、建筑、码头和选关节点收敛透视厚度与碎纹理，用更完整的像素色块表达形体。
- 水面与灯光减少细碎闪烁和泛光，保留紫蓝暮色、暖色船灯和港口空间感。

保留三张主屏和右侧 UI 组件的总体构图、中文功能、夜港配色、像素网格、堆顶取箱逻辑及三格暂存。此版是对原风格的轻度扁平化修订，不增加玩法或系统。
